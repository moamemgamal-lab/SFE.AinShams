01 / ABOUT THE SESSION

More Than Just A Form.

Beyond the Form is a practical learning experience focused on building a complete digital registration system. Instead of treating registration forms and websites as separate tools, participants will learn how they work together to create a professional online experience for events, initiatives and activities. The session introduces Tally for form creation, HTML and CSS for website development, and GitHub Pages for publishing.

▤

Organized Registration

Understand how digital registration systems help organizers collect participant information, structure questions, manage submissions and simplify the registration process.

⌘

Professional Website

Learn how to turn event information into a well-organized landing page with sections for the event overview, agenda, speaker, outcomes and registration.

⌁

Online Publishing

Move beyond working locally on your computer. Learn how to upload your website files and make your project accessible online through GitHub Pages.

02 / MODULE ONE

Build Your Registration Form.

The first stage focuses on building a structured digital registration form. Participants will explore Tally and understand how to design a form that collects information clearly and efficiently.

01 — INTRODUCTION TALLY

Getting Started with Tally

Discover the platform, understand its interface and explore how online forms can be used for events and activities.

  • Introduction to Tally.
  • Understanding the form builder.
  • Creating a new form.
  • Exploring available question types.
02 — FORM DESIGN STRUCTURE

Building the Registration Form

Create a registration form with an organized structure and the information required from participants.

  • Participant name and contact details.
  • Email and phone number fields.
  • Multiple-choice questions.
  • Required questions and field organization.
03 — CUSTOMIZATION DESIGN

Customizing the Form

Improve the registration experience through visual customization and clear form organization.

  • Form titles and descriptions.
  • Colors and visual appearance.
  • Question arrangement.
  • Confirmation messages.
04 — MANAGEMENT RESPONSES

Managing Registration Responses

Understand what happens after a participant submits the form and how organizers can access the collected data.

  • Viewing submitted responses.
  • Understanding response management.
  • Testing the registration process.
  • Sharing the registration link.
Explore Tally Platform ↗
03 / MODULE TWO

Design Your Landing Page.

The second stage focuses on transforming event information into a professional website. Participants will understand the structure of a landing page and how HTML and CSS work together to create a complete digital experience.

01 — HTML STRUCTURE

Understanding HTML

HTML provides the structure of the website. Learn how different elements organize content and create the foundation of a landing page.

  • HTML document structure.
  • Headings and paragraphs.
  • Sections and containers.
  • Links, images and buttons.
  • Organizing page content.
02 — CSS STYLING

Styling with CSS

CSS controls the visual appearance of the website and helps transform a basic HTML structure into a professional design.

  • Colors and backgrounds.
  • Typography and font sizes.
  • Spacing and alignment.
  • Cards, borders and buttons.
  • Layouts and visual consistency.
03 — LAYOUT WEB DESIGN

Building the Page Sections

Understand how to organize information and create a clear navigation experience for visitors.

  • Hero and introduction section.
  • About and workshop details.
  • Agenda and learning outcomes.
  • Speaker information.
  • Registration call to action.
04 — RESPONSIVE MOBILE DESIGN

Responsive Design

Learn why a website should adapt to different screen sizes and how to make its layout suitable for mobile devices and desktop screens.

  • Understanding responsive layouts.
  • Mobile-friendly navigation.
  • Flexible grids and containers.
  • Adjusting cards and typography.
  • Testing different screen sizes.
04 / MODULE THREE

Publish with GitHub Pages.

After creating the website, the next step is publishing it online. GitHub Pages allows participants to host a static website directly from a GitHub repository and share it through a public website link.

01 — ACCOUNT GITHUB

Getting Started with GitHub

Understand the GitHub platform and how repositories are used to organize and store project files.

  • Introduction to GitHub.
  • Creating or accessing an account.
  • Understanding repositories.
  • Creating a new repository.
02 — UPLOAD FILES

Uploading Website Files

Prepare the website project and upload its files to the repository in an organized structure.

  • Preparing HTML and CSS files.
  • Uploading images and assets.
  • Understanding the index.html file.
  • Checking repository contents.
03 — DEPLOYMENT PUBLISHING

Configuring GitHub Pages

Explore the publishing settings and learn how to deploy a static website from the repository.

  • Opening repository settings.
  • Finding GitHub Pages.
  • Selecting the deployment source.
  • Publishing from the selected branch.
04 — LIVE WEBSITE FINAL LINK

Testing and Sharing the Website

After deployment, access the published website, check its content and share the live link.

  • Opening the published website.
  • Testing navigation and buttons.
  • Checking images and page layout.
  • Sharing the website URL.
Explore GitHub ↗
05 / MODULE FOUR

Connect Everything. Make It Work.

A professional registration experience is not just about having a form and a website. It is about connecting both so visitors can discover an event and complete registration without unnecessary steps.

01 — REGISTRATION LINK

Direct Tally Integration

Connect the registration button on the landing page to the published Tally form link. When visitors click the button, they are directed to the registration form.

  • Getting the public form link.
  • Adding the link to website buttons.
  • Testing the registration journey.
02 — EMBEDDED FORM

Embedding Tally into the Website

Explore the possibility of displaying the Tally form directly inside a landing page, allowing visitors to complete registration without leaving the website.

  • Understanding form embedding.
  • Using the provided embed code.
  • Placing the form in the page layout.
  • Testing the embedded experience.
